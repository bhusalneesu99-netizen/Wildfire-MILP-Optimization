# Wildfire-MILP-Optimization

This repository contains optimization models developed for wildfire risk reduction through forest treatment planning.

## Files

- Greece.ipynb : Wildfire treatment optimization for Greece
- Portugal.ipynb : Wildfire treatment optimization for Portugal

## Methods

Mixed-Integer Linear Programming (MILP) was used to optimize treatment allocation under area constraints.
